WHAT’S NEW

近期完善，双端同步

更顺手的聊天

内置 GIF 按编号发送；点击弹幕即可复制、播放或下载。发送中的消息会显示状态，失败也能及时看见。

画质按设备来选

低配和低带宽可选 720p / 30 FPS；高配可提高分辨率与帧率。两端都能设置，并记住上次选择。

更容易设置和排障

明暗主题、专用取色器、日志入口与统一数据目录，让常用设置和问题定位更直接。

核心能力

围绕虚拟大厅做完整组网体验

从虚拟网络到语音小队、文件、屏幕、双向远程控制、变声器、消息弹幕，再到公开大厅广场、游戏内 HUD、Minecraft 世界发现、游戏快连与连接诊断，把临时组网需要的能力集成在一起

虚拟局域网

基于 EasyTier 建立虚拟网络。无需公网 IP，优先尝试直连；网络条件不允许时可能经过中继，实际延迟取决于线路与节点。

跨端大厅

电脑端和手机端可以加入同一个大厅，扫码或复制邀请链接都能快速进入

实时语音

大厅内实时语音与语音小队，支持麦克风选择、静音和变声。Windows 可接入 NVIDIA Broadcast / RTX Voice 或 AMD Noise Suppression 虚拟麦克风。

文件夹共享

把资源包、文档、工具或临时文件共享给同大厅成员，减少来回传文件的麻烦

屏幕共享

Windows 和 Android 均可设置 720p、1080p、2K、4K，以及 30、60、120 FPS 和码率上限。支持多人观看，实际画质由设备与网络决定。

远程控制

经对方同意后远程查看与操作设备，支持电脑与手机协作。Android 被控端需系统录屏和无障碍授权，操作范围取决于系统支持。

内置变声器

实时语音变声，内置萝莉音、大叔音等多种音色，开麦聊天更有趣，应用前还能先试听

消息弹幕

直接点击弹幕：文字复制、语音播放、图片保存原图、文件下载。双端可调字号、速度、透明度、轨道与颜色，支持每条随机颜色。

大厅聊天室

文字、语音、图片、GIF 表情与文件消息，支持公开聊天和私聊。内置表情自动准备、按编号传输；图片无损优化，语音边录边压缩。

公开大厅广场

房主可以把大厅公开到广场，陌生人也能在广场看到并一键加入，适合开放房间和找队友

语音小队

把成员分到不同小队，只听同队成员的语音，轻松实现多队伍分组开黑

房主管理

房主可发布滚动公告、设置人数上限、踢出成员，并把大厅发布或下架到公开广场

游戏内 HUD 浮层

游戏中以置顶穿透浮窗显示每位队友的延迟、丢包和谁在说话，可静音、拖动、调透明度与缩放

Minecraft 世界发现

扫描大厅成员开放的 Minecraft 世界（MOTD/版本/人数/延迟），免输 IP 自动注入本机局域网列表一键加入

游戏快连

内置常见联机游戏的端口预设，自动生成“虚拟 IP:端口”直连地址，一键复制

连接 / 网络诊断

聚合成员直连/中继、延迟与丢包给出评分与建议；网络诊断还能检测虚拟网卡、防火墙、UDP 端口与安全软件拦截，并支持一键放行

房间工具

内置掷骰子、倒计时与多人协同待办清单，方便跑团、抽签和团队任务安排

Minecraft 联机助手

检测 Minecraft 安装路径与版本，提供局域网联机图文指南，并可自动为主流启动器关闭局域网正版验证

常用大厅与最近联机

收藏常用大厅一键填入，记录最近进入的大厅与一起玩过的玩家，还能收藏常用队友

全局快捷键

自定义快捷键，支持按键说话、一键静音等操作，不用切出游戏也能控制语音

高级网络配置

提供全局与单大厅级高级参数（KCP/QUIC 代理、延迟优先、P2P/打洞开关等），以及 SOCKS5、端口转发等出口节点设置

本地数据统计

纯本地统计联机时长、加入/房主次数、活跃时段与常玩伙伴排行，绝不上报网络

系统托盘后台运行

桌面端可最小化到系统托盘后台静默运行，还能设置启动后自动隐藏到托盘，语音与大厅保持在线又不占用任务栏

私有化部署

支持自建信令服务，适合想掌控连接入口和数据边界的用户、团队或社群

共享节点与自建节点

默认节点顺序为唯爱厦门、海波中国大陆、海波美国。支持保存自定义节点、浏览和投稿共享节点；邀请信息同步连接配置。

日志与本地数据

设置中查看或导出日志。Windows 配置、日志与缓存统一收纳在 Local/com.mctier.app；Android 数据由系统沙盒管理。

GET STARTED

三步进入同一个局域网

  1. 安装并完成环境检查

    选择对应平台的客户端。Windows 使用原生麦克风和屏幕捕获，不弹出浏览器麦克风授权，仍遵循系统隐私设置。Android 允许创建 VPN 连接，并在使用时授权麦克风或屏幕录制。

  2. 创建大厅，发出邀请

    房主设置大厅名、密码和节点，把二维码或邀请链接发给朋友。加入方使用相同的连接配置，等待虚拟 IP 分配完成。

  3. 开始联机与协作

    按游戏要求使用房主的虚拟 IP 与端口，或使用游戏快连。进入聊天室、语音小队、文件夹共享或屏幕共享开始协作。

私有化

自建自己的信令入口

信令服务源码可获取，按随包许可使用。它负责大厅与连接协调；EasyTier 节点和信令服务是不同组件。

MCTier 信令服务器

包含 源码、Dockerfile 和 README文档，可用于自建 MCTier-WebRTC 信令服务。

下载信令服务源码包
1

准备服务器

准备一台 Linux 服务器、云主机或局域网内 Linux 主机。公网部署填写公网 IP 或域名，局域网部署填写内网 IP。

2

上传并解压压缩包

把 `MCTier信令服务器.zip` 上传到服务器，然后解压进入目录。 

unzip MCTier信令服务器.zip
cd MCTier信令服务器
3

执行部署脚本

按随包 README 配置环境变量并启动。当前 Compose 只绑定 127.0.0.1:8445，需另配反向代理和 TLS 才能对外提供 WSS 服务。 

chmod +x deploy.sh
sudo ./deploy.sh
4

检查服务状态

确认容器正常运行，并查看日志排查端口、域名或网络问题。 

docker compose ps
docker compose logs -f
5

在客户端填写地址

打开 MCTier 设置，把 WebRTC 信令服务器改为你的地址，例如： 

ws://your-server-ip:8445
wss://your-domain.example:8445
6

常用维护命令

普通重启不会重新读取 .env；修改环境变量后需重建容器，修改源码后还需加 --build。反向代理的可信来源按实际部署配置，详见随包 README。 

docker compose restart
docker compose logs --tail=100 -f
# Reload changed .env values
docker compose up -d --force-recreate

HELP

常见问题与排障

连接不上或延迟高，先检查什么？

确认所有成员使用相同的大厅与连接配置，检查节点和信令服务是否可达。内置顺序是唯爱厦门、海波中国大陆、海波美国，默认唯爱；节点距离近不等于一定直连。使用连接诊断查看直连／中继、丢包与延迟，再导出日志排查。

日志和配置在哪里？

优先使用设置中的日志查看／导出入口。Windows 用户数据统一在 %LOCALAPPDATA%\com.mctier.app，运行日志为 mctier.log。旧目录首次启动时迁移；主动下载或导出的文件仍保存在用户所选位置。Android 日志从应用设置导出，数据在系统应用沙盒内。

“一键重置并重启”会恢复出厂设置吗？

不是。桌面端该操作清理 WebView2 网页本地存储、浏览缓存和权限记录，可能重置部分界面偏好；应用配置文件保留。麦克风不可用时，先检查 Windows 隐私设置或 Android 应用权限。

图片和语音会怎样压缩？

图片只采用更小的无损结果，保留尺寸、透明度和动画；压缩收益不明显、超时或繁忙时保留原图。语音以适合人声的低码率边录边编码，属于有损压缩。发送状态不代表对方已收到，接收速度仍受网络影响。

弹幕怎么操作？

直接点击弹幕即可操作：文本复制、语音播放、图片保存原图，文件或音视频附件下载原文件。设置中可调颜色、字号、速度、透明度与轨道；Android 需要允许悬浮窗显示。

屏幕共享怎么选画质？能隐藏系统提示吗？

低配或低带宽建议 720p / 30 FPS；默认 1080p / 30 FPS，码率可自动推荐或手动设置。更高档位需要足够的采集、编码和上行能力。Windows 10 1903+ 与 Windows 11 使用原生采集和 MCTier 选屏界面，不显示独立共享提示窗口；在 MCTier 内停止共享，或离开大厅时自动停止。Windows 捕获边框与 Android 系统录屏授权仍保留。

AMD / NVIDIA 降噪需要什么？

Windows 先安装并启用 NVIDIA Broadcast / RTX Voice，或在受支持设备的 AMD Adrenalin 中启用 Noise Suppression，再到 MCTier 选择对应方式。AMD 输入设备名称为 AMD Streaming Audio Device；未检测到时使用普通麦克风处理。

是 Minecraft 专用工具吗？

不是。MCTier 是通用虚拟局域网工具，可用于兼容的局域网游戏、本地服务访问和临时协作。Minecraft Java 与基岩版能否互联、游戏版本是否兼容，仍取决于游戏本身或额外服务。
